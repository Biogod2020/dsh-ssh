# 本机历史空间核对与中断清理恢复

状态：候选实现，未发布、未替换日常安装；真实原生管理器界面待解锁验收。

历史和文字草稿保存在本机私有磁盘目录，长期保留，不按时间删除。空间核对的结果是可重建的只读快照，不是历史正文的 RAM 缓存。

## 用户会看到什么

侧栏的大小明确标为“已保存历史”，不再将条目索引的字节说成全部文件或物理 SSD 占用。打开本机历史管理器可“核对文件大小”：显示整个历史目录的文件大小合计，包括迁移备份、未提交段、描述索引的未提交尾部和未知保留文件。所选副本的预计清理量使用对应键下观察到的文件大小；共享管理文件不算入某条副本的预计释放量。

文件大小按路径相加，不等于唯一物理块或实际释放空间；稀疏文件、克隆与硬链接会有差别。未读到的文件明确显示统计下限，写入期间或之后发生变化则提示重新核对，不把正常新增段误报为当前孤儿文件。核对本身不会删除文件。未知文件不会自动清除。

如果之前用户已经确认清理、持久屏障已关闭该副本，但删除文件时进程中断，管理器会提供“完成上次的本机清理”。请求带已审阅的会话键和清理代次；服务端先核对整个选择，再逐键检查。重新打开副本后代次推进，旧选择不得删除新副本。确认失败或回执丢失显示未确认，只能先重新核对，不自动重发。普通选择清理与恢复清理均在等待前复制参数，调用者后续修改数组不能转向另一主机。

512 MiB、100 会话、保存满 30 天和推迟 7 天的提醒规则保留。新核对也会提醒有未计入历史的文件或统计不完整；这些提醒不会删除文件或建立 SSH。

## 读取和恢复边界

- 固定只读本机 history 根目录，不接受请求提供的路径，不读取聊天正文、模型设置、cookies 或 SSH 凭据。响应只有大小、数量和散列会话键，不返回文件名。
- 启动时后台核对一次；普通状态、翻页和会话切换只读已有摘要，不重扫目录。管理器打开或用户点击时可重新核对，并发请求合并。
- 扫描不进入写队列，前台追加不用等它；在私有目录中逐项核对元数据，不跟随观察到的符号链接，跳过非私有项目。最多 200,000 个目录项、8 层深度，超出或不可读均标记不完整。
- 观察值不是全文件系统的原子快照或完整性校验。控制器写入会使它过期；实际读取仍核对历史范围/校验值。实际清理仍以持久写入屏障和单写入者为准，不以大小统计为删除授权。
- 恢复清理只能处理先前明确选择且屏障仍关闭的键；未确认的首个副本没有可靠身份信息时保留待核查。该动作不迁移认证、不调用远端 API、不取消或重启远端任务。

## 已有验证

本地完整集合 86 文件 / 776 项通过；typecheck、build 与产物检查通过。专项涵盖正文不可读文件的大小统计、符号链接/非私有目录、未提交段及索引尾部、只读摘要不重扫、并发追加、保留与提醒、跨主机参数快照、旧代次拒绝，以及真实 SIGKILL 后继续已确认清理。单元/路由验证不能替代正式安装归档或原生界面。

[10 万生成事件测量](benchmarks/2026-10-22/storage-inventory-macos.json)：约 104 MB，暖窗 100 次 p95 1.969 ms；新增 30 次写入 p95 1,014 字节；独立文件大小核对 30 次 p95 4.262 ms，文件内容读写均为零，但每次有 241 次显式文件元数据 API 调用。它不是零文件系统成本，也不是原生界面延迟。

测量在全量测试结束后单独运行；同台 Mac、Node 24.16.0，GC 在每个计时样本前执行，未清理系统文件缓存。第一轮与全量测试重叠的计时已排除并在私有诊断中保留原因，未用于上述结果。显式 stat/lstat/readdir/opendir 和 handle.stat 调用另列，不能当成全部内核系统调用或物理磁盘字节。

Gemini 实际审阅后落实了过期计数不展示为当前异常、队列内确定变更、旧归档实际修改单独跟踪，以及不完整统计的下限提示。没有采纳放松私有根目录权限或将丢失回执统一说成“旧选择失效”的建议，分别受已有目录检查和不重放约束限制。

真实安装归档的[后台验收](benchmarks/2026-10-22/storage-inventory-archive-macos.json)通过：不连接 SSH 即可核对历史目录，并完成先前已确认清理的残留文件删除；清理屏障仍阻止旧副本回到历史列表，原远端 PID 不变。该归档夹具通过“已确认清理后恢复生成的旧格式文件”模拟遗留文件；真实 SIGKILL 位点由专项另行验证，不将模拟称为第二次真实杀进程验收。后续补上旧文件在探针后出现的回归，12 项空间专项通过；最终 CI 将包含这个新增用例。
