# 隔离持续运行的验收方法

本项检查安装包中的 Host、真实 SSH、持续新增历史、本机草稿和进程连续性。它不是原生桌面、真实 WAN、模型效果或全应用内存验收。短校准通过不等于 24 小时通过，长时结果须单独读取。

## 冻结条件

调用 `scripts/history-delta-smoke.mjs` 并显式传入 `--soak-seconds=86400`。Node、DSH 和包必须为绝对路径；使用私有临时 Home、生成的 SSH 身份和严格 known_hosts，模型地址只指向未监听的本机测试端口，遥测模块在两端测试 profile 中禁用。没有安装到用户日常 profile，也不连接正式远端。

包 SHA-256、观测器和主夹具的源码 SHA-256 进入报告；另记 Node、平台、架构、CPU 和内存。实际运行时版本须与预置版本一致。开始后保留这份观测，不以修改阈值、删除失败或覆盖旧报告的方式重跑。

1. 每分钟核对原服务、磁盘历史和草稿。服务通过测试专用的认证只读接口返回生成的 nonce、私有 Home 和 PID，并核对原进程出生时间；不能只凭陈旧 PID 文件认定服务未变。
2. 每五次观察追加一条生成事件，并等待该增量落盘。每个 ordinal 只派发一次；丢回执或超时即锁住后续新增，不重发该写入。之后仍保留只读观察和失败。
3. 每次核对当前完整事件前缀及 firstSavedAt，确认原草稿 revision 和文字不变。记录测试控制器、测试远端进程的 RSS；它们不是桌面 guest 的内存。
4. 时间以单调时钟计算，并单列挂钟时间。晚触发超过 5 秒（短校准取半个周期）、两种时钟跳变超过 5 秒、探针间隔过长或样本不足均失败。24 小时至少有预定周期数的 95% 样本；两种时长均须达到目标。
5. 每次观察原子替换私有报告，原有报告拒绝覆盖。中断保留部分记录、`passed: false` 和 `completed: false`；结束后的主报告还须确认测试控制器和生成服务已退出。

正常判定容许上述明确的采样容差，不声称连续观察了两次探针之间的每个瞬间。Mac 的休眠可能使本轮不通过；这种失败须保留，不能当作不存在，也不能用这份同机夹具代替物理远端的睡眠恢复验收。

## 运行与读取

```sh
DSH_HISTORY_SOAK_REPORT=/private/path/new-soak.json \
DSH_HISTORY_ARCHIVE_REPORT=/private/path/new-smoke.json \
node --experimental-transform-types scripts/history-delta-smoke.mjs \
  /absolute/path/dsh /absolute/path/candidate.tgz --soak-seconds=86400
```

开始即输出生成诊断目录；认证 URL 和 cookie 不输出。报告旁的 `.state.json` 仅供定位测试进程，状态文件本身不是进程仍存活的证明。恢复工作时要检查原工具会话或实际进程，不能因为暂时读不到输出就重新派发测试。

`minimum24HoursVerified` 只有运行完成、无失败、样本密度和时长都满足，且要求时长至少 86,400 秒时才为 true。默认不带参数的普通 smoke 明确记录长时检查未执行；CI 的 30 秒校准明确记录此字段为 false。

## 已有检查与剩余工作

30 秒真实 DSH/SSH 校准通过：两次新增、11 次样本，历史前缀、草稿和原进程保持，清理后测试服务退出。失去 ACK 的故障注入只派发一次写入，整轮仍判失败；旧报告保留。真实 SIGTERM 中断保留部分报告且不判通过，测试控制器及生成远端均确认退出。

一次新增的命令行归属检查发现 DSH 改写了进程标题，因而拒绝清理并让校准失败。两份生成夹具随后通过 OS 实际 cwd 的规范路径核对归属并完成清理；未将该失败算作通过。现采用上述认证 nonce/Home/PID 和出生时间检查，已复验中断与正常退出。最终长时观测仍需完成后另行归档。

Gemini 实际审阅本方法，请求 `gemini-3.8-flash-high`，返回 `gemini-3.8-flash-n`，响应 `XpjaasXwOLa-uMYPk7rtgA8`。采纳收紧采样延迟、保留失败报告及明确长时执行状态；单调/挂钟核对、报告不覆盖和清理确认也单独验证。未将其对 macOS 底层时钟实现的描述当作平台实测结论，方法同时核对两种时钟。

原方案的视图内存预算、大目录订阅和大基线解析仍需独立完成。当前八视图上限不等于内存预算，桌面公开桥也没有提供逐视图进程内存统计；保存草稿不能单独证明释放视图不会影响终端持有者或未确认操作。本机测量、公开契约和原生验收仍是后续工作的依据，不能据本项通过认定第 0—3 轮全部完成。
