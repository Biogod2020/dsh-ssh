# 本机磁盘历史缓存（开发分支，尚未发布）

已打开的远端会话会在后台保存到本机磁盘。退出 DSH、重启本机或暂时无法连接 SSH 后，仍可阅读上次保存的历史。缓存没有自动过期或自动删除规则；最近会话的 RAM 保活是独立的性能优化，不控制磁盘副本的寿命。

## 使用

- 侧栏下方的 **本机历史缓存 / Local history cache** 显示占用空间。打开后可按主机、项目筛选，阅读已保存副本，勾选一条或多条会话后清除。
- 从侧栏打开已保存的远端会话时，原聊天区域先显示本机只读历史，再连接远端并恢复原生聊天界面。远端不可达时，本机历史仍可阅读。
- 达到 **512 MiB、100 条会话或有副本保存满 30 天**，界面会主动提示检查缓存。可以选择清除，或推迟 7 天提醒；提醒不会自动删除数据。
- 清除只影响本机副本。远端会话、模型配置和任务均不改动；下一次明确打开会话时可以重新同步。已在后台派发的旧读取不能把清除的副本立即写回来。

首次打开会话后，会按页补齐其事件历史；未完成时显示“完整历史仍在同步”。后续根据远端活动时间检查变化，已有完整副本只补齐新增事件。没有打开过的会话不会自动整批下载。

本机副本保存聊天文字和事件记录，包括工具调用/结果；图片、文件等附件的二进制内容仍由远端提供。只读预览使用文字节点，不执行历史中的 HTML 或脚本。原生聊天恢复仍需获取远端当前尾页和实时状态，本机缓存不会伪造当前运行状态或重新执行历史命令。

## 保存与边界

数据位于本机 DSH Home 的 `remote-workspaces/history/`，目录权限 `0700`、文件权限 `0600`。键包含主机身份、远端工作区身份和会话身份，避免不同主机的同名会话混用。文件原子替换；损坏或权限不安全的源文件保留并报告错误，不覆盖用户资料。

这里只保存用户要求的会话历史，不复制 SSH 凭据、模型认证配置、浏览器 Cookie 或连接票据。历史本身可能包含用户消息和命令输出，应按本机私有资料管理。

## 已完成验证（2026-10-22）

- 73 个测试文件、645 项测试通过；typecheck、build、产物检查通过。
- DSH `0.2.1-rc.2`、真实生成密钥 SSH、隔离 HOME：1,100 条生成的测试消息，1,104 条事件，额外读取两页历史后完整落盘。
- 控制进程重启后，不启动 SSH 就能读取完整本机副本。
- 清除选中的副本后其他副本保留，远端历史游标未变化；再次明确打开可重新同步。
- 原生桌面重新启动后，在 SSH 未连接时从缓存管理入口阅读磁盘历史；关闭测试 SSH 服务后，从统一侧栏打开会话仍在原聊天区域显示保存的历史。
- 持久化多年后仍保留、提醒及推迟、跨主机隔离、损坏/权限/路径处理、清除和后台写入竞态均有回归测试。

测试消息是明确生成的隔离数据，不代表模型回答效果。开发分支尚未替换日常安装，也未发布到 GitHub/npm。
