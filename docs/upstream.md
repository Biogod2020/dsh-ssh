# 来源与维护范围

本项目从 `zhu1090093659/dsh-web` 的 SSH 模块独立派生，不要求安装其插件全家桶。

- 基线：上游 `v0.3.24`，commit `221d0a7a8c12d8124db9c214ec1b1bb8ad4fa5e4`。
- 原包：`@linxin666/dsh-ssh@0.3.24`，Apache-2.0。
- 本包：`@jay-local/dsh-ssh-ops`，保留包名以支持既有本地安装升级，不发布 npm。

独立维护的主要改动包括严格 known_hosts 验证、移除已派发操作重放、官方 HTTP / WebSocket 认证、移除匿名统计、完整远端 DSH 工作区、多终端与有界显示恢复、传输队列和结果检查、集群流式执行与历史回执。

`0.3.24-jay.25` 适配 DSH `0.2.1-alpha.4`，保留旧版兼容。新版通过 `engines.dsh` 声明精确支持版本，并使用原生 `sidebar.panellist` / `main` 导航；页面切换保留原面板树。远端首次安装固定版本与完整性校验，已有兼容服务继续复用。

更新采用人工审查和隔离验收，不直接用原上游文件覆盖本地实现。源码中的共享副本在本仓库维护。原作者与第三方依赖的许可见 LICENSE、NOTICE 和安装包内各依赖的许可文件。
