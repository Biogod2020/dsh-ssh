两组远端原 PID 均保留，loopback qdisc 和原卸载设置恢复检查通过。差量写入收益稳定；恢复时延基本相同，不宣称重连显著加速。正常网络的五秒后台恢复目标只适用于预先约定的 RTT ≤80 ms，本组没有事后套用或放宽该目标。

初次复制分别为单次 29.739 秒和 36.396 秒，不能据此给出冷路径 p95，也不能宣传候选初次复制更快。这些是后台协议与存储测量，原生编辑器与导航验收仍独立保留。
